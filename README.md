# Arbol binario de atletismo

## Objetivo
Implementar un arbol binario en Java usando disciplinas
del atletismo como datos de sus nodos.

## Disciplinas utilizadas
- Salto largo
- Salto alto
- Carreras de vallas
- Carreras de fondo
- 80 metros planos
- 100 metros planos
- Lanzamiento de jabalina

## Archivos
- NodoArbol.java: estructura generica de los nodos.
- Main.java: construccion y recorrido del arbol.
- diagramas.md: representacion de las clasificaciones.

## Funcionamiento
El programa crea nodos con nombres de disciplinas,
los conecta mediante referencias izquierda y derecha
y realiza un recorrido recursivo.

## Evidencias
Se agregaran capturas de la ejecucion del programa
y de los resultados obtenidos.
